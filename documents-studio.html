Documents & PDF Studio

Browser में document तैयार करें, format करें, TXT डाउनलोड करें या Print के जरिए PDF में save करें।

Free local tool · आपका document किसी server पर upload नहीं होता। Draft इसी device के local browser में अपने-आप save होता है; Clear दबाने पर saved draft भी हट जाता है। PDF export के लिए Print dialog में “Save as PDF” चुनें। PDF text extraction इसी browser में होता है; file server पर upload नहीं होती। Scanned PDF के लिए OCR अभी उपलब्ध नहीं है। PDF Merge और Split browser में locally काम करते हैं। Optional SHIF-A AI document assistance के लिए verified login और Gemini API server-side credentials जरूरी हैं।

PDF Merge

2 से 10 PDF को एक file में जोड़ें। हर file 20 MB तक, कुल 50 MB और merged output 300 pages तक सीमित है।

PDF Split

एक PDF से चुने हुए page ranges अलग-अलग PDF files के रूप में डाउनलोड करें। उदाहरण: 1-3,5,8-10

Split के लिए PDF अधिकतम 20 MB और 100 pages तक हो सकती है।

Import PDF Text

20 MB तक और अधिकतम 100 pages वाली PDF से selectable text निकालकर editor में लाएँ। Scanned image PDF का OCR अभी नहीं है।

PDF text extraction happens locally in your browser. PDF.js library load करने के लिए internet connection चाहिए।
