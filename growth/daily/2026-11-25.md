### Article body

An AI video prompt is a set of instructions describing what should appear in a clip and how the scene should look. A short prompt can work for a simple idea, but a more structured description helps reduce ambiguity. It does not guarantee that an external video model will follow every instruction exactly.

Before writing, decide what the viewer should notice first. Then describe the scene in a consistent order.

### 1. Name the main subject

Start with the person, object, animal or environment that matters most. Avoid describing five unrelated subjects in one sentence. If a reference image is being used, identify the subject that should remain recognisable.

### 2. Describe one clear action

Use a visible action rather than a vague mood. “A paper boat slowly drifts across a rain puddle” gives a clearer instruction than “a beautiful cinematic scene.” Keep the action physically understandable and avoid asking the model to perform too many unrelated movements at once.

### 3. Set the location and background

Mention the setting, time of day and a few relevant background details. For example: “a quiet courtyard after light rain, early morning, soft reflections on the ground.” Background details should support the main subject rather than compete with it.

### 4. Choose the camera framing

Specify whether the shot is a close-up, medium shot or wide shot. If camera motion matters, describe one movement such as a slow push-in, a gentle pan or a stationary camera. Too many camera instructions can conflict with each other.

### 5. Describe lighting and colour

Use practical visual terms: soft daylight, warm window light, overcast sky, cool blue shadows or a muted colour palette. Avoid stacking several opposite lighting styles in the same prompt.

### 6. Keep the visual style consistent

Choose one main style—documentary realism, clean 2D illustration, stop-motion look or a simple product demonstration. If the prompt needs a particular reference image to stay consistent, say which visible details should remain unchanged.

### 7. Add continuity and exclusions

For a photo-to-video workflow, describe what may move and what should remain still. For example: “keep the background architecture unchanged; only the leaves move gently in the breeze.” Add a small number of important exclusions, such as “no extra text or logos,” when they matter to the scene.

### A simple prompt template

“[Subject] performs [one action] in [setting and time]. Use [camera framing and one camera movement]. Lighting is [lighting], with a [visual style] look. Keep [important details] consistent. Avoid [one or two unwanted additions].”

### Review the prompt before using it

Check that the subject, action, setting and camera instructions do not contradict one another. Remove repeated adjectives. If you are using a reference image, state which features must stay consistent and which movement is allowed. Then test the prompt in the external tool you have chosen and review that tool's current terms and limits.

### What SHIF-A does—and does not do

SHIF-A's Video Prompt Builder prepares text prompts. It does not render a video, guarantee a particular model output or activate a paid external generation service. The finished video depends on the separate tool used with the prompt.
