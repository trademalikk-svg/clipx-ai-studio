## 1. Product-truth guardrails

All content below reflects the current repository implementation:

- Manual Clip Cutter: the user chooses exact start and end times.
- Automatic Shorts Maker: creates consecutive, fixed-duration segments (30, 60 or 90 seconds). It does not understand story meaning or automatically choose viral/highlight moments.
- Source-video processing in Free Browser Mode happens locally in the browser/device; cloud rendering is disabled.
- Caption Studio can create draft multilingual captions in the browser with a Whisper model in supported browsers/devices. The first model download may be around 150 MB or more. The transcript must be reviewed. Manually written captions can be exported as SRT.
- Thumbnail Studio is a browser-based 1280 × 720 canvas with five available styles. It uses the user's own image and text; it is not a generative-AI photo tool and does not guarantee views.
- Video Prompt Builder creates text prompts only; it does not generate a video.
- Use footage, images, logos and music only when owned or properly licensed.

# Before Editing Video in Your Browser: 7 Checks for a Smoother Workflow

Browser-based video editing can be convenient because you can start from a supported browser without installing a large desktop editor. But the result still depends on the source file, available device resources and browser capabilities. A little preparation can prevent wasted time.

## 1. Keep an original copy of your video

Before trimming or exporting, keep the source file unchanged. Work from a copy when possible. This gives you a safe fallback if an export fails or you want to try a different cut.

## 2. Check available memory and storage

Video decoding and export can use substantial device resources. Close tabs and apps you do not need, and make sure the device has enough free storage for the source file and exported clips. Large files may take longer or fail on devices with limited memory.

## 3. Test a short section first

Do not begin by processing the entire recording. Choose a short section, set the start and end points, export it and play the result. Check the picture, audio and timing before repeating the workflow on the full video.

## 4. Understand what the tool does

A manual cutter lets you choose exact start and end times. A duration-based splitter creates consecutive segments of a selected length. These are different workflows. A fixed-duration split does not understand the story and does not automatically identify the most useful highlights.

With ClipX Free Browser Mode, the selected source video is processed locally in the browser/device and cloud video rendering is disabled. Device memory, browser support and source-file characteristics still affect performance.

## 5. Choose the frame before adding text

Pick the aspect ratio that matches the destination: 9:16 for vertical Shorts/Reels, 16:9 for landscape video, or 1:1 for square layouts. Check that the important subject remains visible after cropping. If the source is horizontal, a vertical crop may remove useful content at the sides.

## 6. Review captions instead of trusting the first draft

Automatic speech recognition can mishear names, numbers, accents and mixed-language speech. Listen to the original audio while correcting the transcript. Check line breaks and timestamps, then preview captions on a phone-sized screen. If you export an SRT file, verify that the text and start/end times are correct.

## 7. Play the exported file and check usage rights

Watch the final clip from beginning to end. Confirm that the audio is present, the cut does not interrupt a sentence, captions are readable and the video plays correctly. Use footage, images, music and logos only when you own them or have permission to use them.

### Quick pre-edit checklist

- Original source file kept safely.
- Browser and device have enough available resources.
- Short sample export tested.
- Manual or fixed-duration method chosen intentionally.
- Aspect ratio checked before final export.
- Captions reviewed against the audio.
- Final clip played from start to finish.
- Media usage rights checked.

### Frequently asked questions

**Why can browser video export fail on a phone?**  
Large files, limited memory, browser codec support and available storage can affect decoding and export. Try a short sample first and close unnecessary tabs.

**Does a duration-based splitter choose the best moments?**  
No. It divides the source into consecutive segments based on duration. You must review the clips and select the useful moments.

**Does ClipX upload the source video to cloud rendering?**  
In the current Free Browser Mode, the selected source video is processed locally in the browser/device and cloud rendering is disabled. Some browser tools may download supporting model files from third-party CDNs; that is separate from uploading the source video to ClipX cloud rendering.
