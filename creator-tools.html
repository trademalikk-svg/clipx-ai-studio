Speech to Text

Thumbnail Studio

वैकल्पिक फोटो चुनें, शीर्षक और छोटा विवरण लिखें, फिर पाँच design styles में से चुनकर thumbnail बनाएँ। फोटो और text इसी page के canvas में मिलाए जाते हैं। डाउनलोड करने से पहले thumbnail का preview जाँचें और केवल वही image इस्तेमाल करें जिसका उपयोग करने का अधिकार आपके पास हो।

Script Writer

वीडियो का विषय और format चुनकर एक शुरुआती template draft बनाएँ। यह सामान्य template है، researched या verified AI script नहीं। रिकॉर्डिंग से पहले facts، names، dates और claims स्वयं जाँचें۔

Caption Helper

हर subtitle को अलग line में लिखें। यह tool हर line को तीन सेकंड का default timing देकर SRT file बनाता है। वास्तविक video के साथ timing को subtitle editor में समायोजित करें।

My Projects

सेव किए गए text projects इसी browser के local storage में रहते हैं، cloud account या backup में नहीं। Browser data साफ करने से projects हट सकते हैं۔

क्या सभी tools AI से चलते हैं?

नहीं। Thumbnail maker, script writer और SRT helper template/browser-based utilities हैं। Voice और speech features browser/device support पर निर्भर हैं।

क्या मेरी files server पर upload होती हैं?

इस Creator Tools page का thumbnail preview canvas और text project storage browser में काम करते हैं। Speech recognition आपके browser के speech service से process हो सकता है। Browser/network behaviour अलग हो सकता है; संवेदनशील files या निजी जानकारी इस्तेमाल न करें।

क्या मैं commercial videos में output इस्तेमाल कर सकता हूँ?

आपको अपनी photos, music, footage और अन्य assets के अधिकार स्वयं सुनिश्चित करने होंगे। Generated text और subtitles को publish करने से पहले जाँचें।

क्या यह mobile पर काम करेगा?

कई सुविधाएँ आधुनिक mobile browsers में चल सकती हैं، लेकिन canvas export، speech recognition और file handling device/browser के अनुसार बदलते हैं।
