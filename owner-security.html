OWNER-ONLY SECURITY

Owner Direct Passkey Login

Fingerprint, face unlock, device PIN या supported authenticator से sign-in करें। SHIF-A को आपका fingerprint/face data नहीं मिलता; verification आपके device और browser के WebAuthn system में होती है।

Security service जाँची जा रही है…

यह discoverable passkey flow है—पहले email या Owner ID लिखने की जरूरत नहीं।

Passkey Management

पहली बार passkey जोड़ने से पहले इस browser में verified Owner session होना जरूरी है। नए device पर enrollment के लिए सामान्य login और MFA policy लागू रहेगी।

जरूरी जानकारी

  • Fingerprint/face/iris का raw data SHIF-A server पर store नहीं होता।
  • फोन का OS biometric या device screen-lock PIN इस्तेमाल कर सकता है; website यह तय नहीं कर सकती कि हर बार fingerprint ही मांगा जाए।
  • Eye/iris तभी उपलब्ध होगा जब device authenticator और OS उसे WebAuthn के जरिए support करें। सामान्य camera से retina scan नहीं किया जाएगा।
  • यह passkey feature Supabase Auth का experimental feature है। Production activation से पहले project configuration और origin verify करना जरूरी है।

Owner ID / Password Recovery

इस project में Owner ID आपका verified login email है। अगर ID याद नहीं है, तो वही email इस्तेमाल करें जिससे SHIF-A account verify किया गया था। सुरक्षा के लिए यह पेज account मौजूद होने या न होने की जानकारी नहीं देगा।

नया Password सेट करें

One-time Recovery Codes

8 backup codes बनेंगे। इन्हें केवल एक बार दिखाया जाएगा। हर code एक बार ही इस्तेमाल हो सकता है और 365 दिनों में expire होगा। Generate करने के लिए verified Owner session और Supabase TOTP MFA का AAL2 जरूरी है।

इन codes को अभी सुरक्षित offline जगह पर लिखें। इस पेज को बंद करने के बाद दोबारा नहीं दिखाया जाएगा।








एक Recovery Code इस्तेमाल करें


यह विकल्प केवल पहले से signed-in और server-verified Owner session में अतिरिक्त one-time verification के लिए है। यह अकेले login या MFA bypass नहीं करता।
