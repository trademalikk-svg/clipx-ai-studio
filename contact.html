Bug या सुझाव रिपोर्ट करें

तकनीकी समस्या या feature suggestion के लिए हमारे सार्वजनिक GitHub issue tracker का उपयोग किया जा सकता है। GitHub account से sign in करना पड़ सकता है।

GitHub पर Issue / Feedback भेजें

रिपोर्ट में केवल समस्या का नाम, इस्तेमाल किया गया browser/device, समस्या दोहराने के सामान्य चरण और दिखा हुआ error message लिखें।

आपकी सुरक्षा

  • Password, API key, OTP, payment details या निजी पहचान की जानकारी कभी रिपोर्ट में न लिखें।
  • निजी वीडियो, फोटो या दस्तावेज़ सार्वजनिक issue में अपलोड न करें।
  • GitHub issue सार्वजनिक हो सकता है और दूसरे लोग उसे देख सकते हैं।
  • अगर आप नाबालिग हैं, तो सार्वजनिक रिपोर्ट भेजने से पहले माता-पिता या अभिभावक की मदद लें।

यह पेज स्वयं कोई संदेश या form data collect या submit नहीं करता। GitHub पर जाने के बाद GitHub की अपनी privacy policy और terms लागू होंगी।
