SHIF-A AI इस्तेमाल करने की गाइड

Android मोबाइल और कंप्यूटर पर SHIF-A का उपयोग करने के चरण। यह guide वास्तविक उपलब्ध सुविधाओं के अनुसार अपडेट होगी।

1. Login और शुरुआत

  1. SHIF-A वेबसाइट खोलें और अपने मौजूदा account से Login करें।
  2. Login के बाद My Workspace खोलें।
  3. Account समस्या होने पर Support/Contact का उपयोग करें। Password, OTP या recovery code किसी को न भेजें।

2. Main Workspace समझें

  • Command Center: नया काम शुरू करने की मुख्य स्क्रीन।
  • Left Menu: Chat, Coding, Image, Video, Voice और दूसरे विभागों तक पहुँच।
  • Right Panel: Projects और Recent Activity का status।
  • Help: इसी guide से संबंधित निर्देश खोलें।

मोबाइल पर Menu बटन दबाकर navigation खोलें।

3. Universal AI Command Box

  1. काम साफ शब्दों में लिखें—क्या बनाना है और किस उद्देश्य से।
  2. Auto Mode: SHIF-A उपलब्ध tool का सुझाव देता है।
  3. Manual Mode: आप खुद tool चुनते हैं।
  4. Project Mode: project context से काम करने के लिए है; वास्तविक project backend जुड़ने तक यह save/execute नहीं करता।
  5. सुझाए गए tool की availability देखकर उसे खोलें।

अभी Command Box tool recommendation करता है। यह अपने-आप AI model को prompt नहीं भेजता और task complete होने का दावा नहीं करता।

4. Projects का उपयोग

  1. My Projects खोलें।
  2. Project का नाम, विवरण और category भरें।
  3. Project save सुविधा backend जुड़ने के बाद सक्रिय होगी।

फिलहाल Project page interface preview है। कोई project browser या server पर save नहीं होता।

5. AI Tools की स्थिति

  • Available: मौजूदा browser/tool workflow उपयोग किया जा सकता है।
  • Limited: केवल बताए गए सीमित features उपलब्ध हैं।
  • Coming Soon: अभी उपयोग के लिए तैयार नहीं।

उदाहरण: AI Coding Studio में starter templates, editor, preview और source export उपलब्ध हैं; model-based code generation या APK compilation उपलब्ध मानकर न चलें।

6. Files और Project Context

  • केवल जरूरी और अनुमत files जोड़ें।
  • File type और size जाँचें।
  • Private documents तभी दें जब संबंधित tool को उनकी जरूरत हो।
  • अभी Project Files upload और version history connect नहीं हैं।

7. Task Status का अर्थ

  • Draft — तैयार किया जा रहा है।
  • Queued — शुरू होने की प्रतीक्षा में।
  • Running — backend ने काम शुरू होने की पुष्टि की है।
  • Needs Review — परिणाम की जाँच जरूरी है।
  • Completed — परिणाम सफलतापूर्वक सेव हुआ है।
  • Failed — काम पूरा नहीं हुआ।
  • Cancelled — काम रोक दिया गया।

SHIF-A में ये वास्तविक status तभी दिखेंगे जब connected backend इन्हें लौटाएगा।

8. Account Safety

  • मजबूत और अलग password रखें।
  • जहाँ उपलब्ध हो MFA या passkey सक्षम करें।
  • Recovery codes सुरक्षित offline जगह पर रखें।
  • Password, OTP, recovery code और secret API key किसी के साथ साझा न करें।
  • Owner controls केवल अधिकृत Owner account के लिए हैं।

9. सामान्य समस्याएँ

  • Login नहीं हो रहा: इंटरनेट जाँचें, पेज reload करें और account status देखें।
  • Tool नहीं खुल रहा: उसका Available/Limited/Coming Soon status देखें।
  • Command suggestion नहीं मिल रहा: काम को छोटे और स्पष्ट शब्दों में लिखें या Manual Mode चुनें।
  • Project save नहीं हो रहा: Project backend अभी connect नहीं है; बार-बार submit न करें।
