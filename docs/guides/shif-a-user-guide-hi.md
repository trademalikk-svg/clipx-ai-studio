# SHIF-A AI — इस्तेमाल करने की हिंदी गाइड

**स्थिति:** शुरुआती गाइड ड्राफ्ट  
**लक्ष्य:** Android मोबाइल और कंप्यूटर पर SHIF-A AI चलाने के सरल निर्देश।  
**नोट:** जिन सुविधाओं का AI backend अभी जुड़ा नहीं है, उन्हें Coming Soon या Limited बताया जाएगा।

## 1. SHIF-A में प्रवेश
1. SHIF-A वेबसाइट खोलें।
2. अपने मौजूदा account से Login करें।
3. Login के बाद My Workspace खोलें।
4. Account या access से जुड़ी समस्या दिखे तो Support/Contact का उपयोग करें। अपना पासवर्ड या recovery code किसी को न भेजें।

## 2. Main Workspace समझें
- **Home / Command Center:** मुख्य स्क्रीन जहाँ से नया काम शुरू होता है।
- **Left Menu:** Chat, Coding, Image, Video, Voice, Writing, Business और अन्य विभाग।
- **Universal AI Command Box:** अपने काम को सामान्य भाषा में लिखें।
- **Projects:** किसी एक लक्ष्य से जुड़े chats, files और tool sessions को एक जगह रखें।
- **Activity:** हाल के काम और उनके वास्तविक status देखें।
- **Help:** संबंधित विभाग की गाइड खोलें।

मोबाइल पर menu खोलने के लिए ऊपर का navigation/menu बटन उपयोग करें। स्क्रीन के अनुसार लेबल बदल सकते हैं।

## 3. नया Project बनाना
1. My Projects खोलें।
2. New Project चुनें।
3. प्रोजेक्ट का स्पष्ट नाम लिखें, जैसे “मेरी वेबसाइट”।
4. जरूरत हो तो छोटा विवरण और category जोड़ें।
5. Create दबाएँ।
6. प्रोजेक्ट खोलकर उसी के अंदर chat, files और उपलब्ध tools का उपयोग करें।

Project feature उपलब्ध होने से पहले यह प्रक्रिया दिखाई नहीं देगी; तब तक project data सेव होने का दावा न मानें।

## 4. Universal Command Box का उपयोग
1. काम साफ शब्दों में लिखें: क्या बनाना है और किस उद्देश्य से।
2. **Auto Mode:** SHIF-A सही विभाग सुझाएगा।
3. **Manual Mode:** आप स्वयं विभाग चुनेंगे।
4. **Project Mode:** चुने हुए प्रोजेक्ट का अनुमत context उपयोग होगा।
5. सुझाए गए tool और action की समीक्षा करें।
6. जरूरत होने पर पुष्टि दें और काम शुरू करें।

उदाहरण: “मेरे छोटे व्यवसाय के लिए एक साधारण वेबसाइट का शुरुआती ढाँचा बनाओ।”

अगर संबंधित AI service उपलब्ध नहीं है, तो SHIF-A को साफ बताना चाहिए कि backend अभी जुड़ा नहीं है।

## 5. Tools की उपलब्धता कैसे समझें
- **Available:** बताया गया browser/tool workflow अभी इस्तेमाल किया जा सकता है।
- **Limited:** कुछ सुविधाएँ उपलब्ध हैं; विवरण पढ़ें।
- **Coming Soon:** अभी उपयोग के लिए तैयार नहीं।

उदाहरण के लिए, AI Coding Studio में starter templates, editor, preview और source export उपलब्ध हो सकते हैं; AI से code generation या Android APK compilation उपलब्ध मानकर न चलें जब तक वह स्पष्ट रूप से चालू और जाँचा न गया हो।

## 6. Files और Project Context
- केवल जरूरी और अनुमत फाइलें जोड़ें।
- फाइल का नाम, प्रकार और आकार जाँचें।
- निजी दस्तावेज़ केवल तभी अपलोड करें जब उस tool को उनकी जरूरत हो।
- किसी दूसरे project या account की फाइल का access साझा न करें।
- Download या export से पहले सही output चुनें।

## 7. Task Status का अर्थ
- Draft: अभी तैयार किया जा रहा है।
- Queued: शुरू होने की प्रतीक्षा में।
- Running: backend ने काम शुरू होने की पुष्टि की है।
- Needs Review: परिणाम की जाँच जरूरी है।
- Completed: परिणाम सफलतापूर्वक सेव/तैयार हुआ है।
- Failed: काम पूरा नहीं हुआ; error पढ़ें।
- Cancelled: काम रोक दिया गया।

## 8. सुरक्षा और Account
- मजबूत, अलग पासवर्ड रखें।
- उपलब्ध होने पर MFA/passkey सक्षम करें।
- Recovery codes सुरक्षित ऑफलाइन स्थान पर रखें।
- किसी को password, OTP, recovery code या secret key न दें।
- Owner Control Center केवल अधिकृत Owner account के लिए है।

## 9. समस्या आने पर
- Login नहीं हो रहा: इंटरनेट जाँचें, पेज reload करें और सही account से प्रवेश करें।
- Tool नहीं खुल रहा: availability status और आवश्यक browser support देखें।
- Upload विफल: file type/size जाँचें और दोबारा प्रयास करें।
- काम अटका है: Activity में वास्तविक status देखें; बार-बार submit करने से duplicate task बन सकता है।
- कोई सुविधा Coming Soon है: उसका backend उपलब्ध होने तक उसे इस्तेमाल नहीं किया जा सकता।

## 10. Guide अपडेट नीति
हर नया feature जोड़ने के साथ उसकी guide, supported file types, limits, screenshots/steps और troubleshooting अपडेट होंगे। गाइड में केवल tested behavior को Working कहा जाएगा।
